/ privacy

Your keys stay on this PC.

Before you paste a key, the app tells you exactly where it goes — this PC's own settings file, and nowhere else. Every request goes straight from your machine to that provider. There's no server of ours in the middle, because there isn't one.

Set up OpenRouter
Your API key never leaves this computer. It's saved straight into this app's own local settings file — never sent to any server except the provider's own API that the key already belongs to.

/ install

Running in about a minute.

There's no hosted download yet — it's pre-release. You'll need Node.js 18+ and Git.

  1. 1
    Clone and install

    Three commands in any terminal.

  2. 2
    Let the setup scan

    The first-run wizard finds the tools you're already signed into.

  3. 3
    Click the tray icon

    That's the whole app. It starts with Windows from then on.

Windows PowerShell
PS C:\> git clone https://github.com/Gubbavarshith/aiusage
PS C:\> cd aiusage
PS C:\aiusage> npm install
PS C:\aiusage> npm start
# want an installer instead? npm run build

/ questions

Short answers.

Will it slow my PC down?

It sits in the tray and checks a handful of small usage endpoints every two minutes. Nothing else runs in the background.

Do I need API keys?

Only for OpenRouter, Z.ai, SiliconFlow, DeepInfra, Baseten, Experiential Labs, or a custom endpoint. The other seven reuse the login you already have.

What happens if I uninstall it?

The installer removes the app's settings and cache too — including any keys you pasted. A reinstall starts completely fresh.

What if a provider changes its API?

That one tab shows a clear error until it's fixed; the rest keep working. Report it on GitHub.

Is there a Mac version?

This is the Windows app. On macOS, look at OpenUsage, the menu-bar app it started from.
